# 🎮 Chatify - The Ultimate Gaming Overlay

**Chatify is a communication tool made for gamers who value privacy, efficiency, and seamless performance.**

It runs as a lightweight overlay directly on top of your game window, so you never need to tab out again.

---

## 🚀 What is Chatify?

A custom Python-based overlay built on secure chat technology. Stay fully focused on your heist, race, or roleplay session without distractions.

![Chatify Preview](https://img.itch.zone/aW1hZ2UvNDIwNTg3OC8yOTg4MTkyNC5wbmc=/347x500/9AdnA8.png)

---

## ✨ Key Features

- **📌 Always-on-Top:** Overlay stays permanently above your game window.
- **🔥 Burn-After-Reading:** Press `F2` to instantly rotate rooms for privacy.
- **🔗 Instant Link Sharing:** Click the header to copy your invite link.
- **⚡ High Performance:** FPS-friendly Dark Mode designed for minimal impact.
- **🌍 Multi-Language:** Quickly toggle between **English** and **German** directly in the app.
- **🔔 Show / hide overlay:** Choose Your own Hotkey to show or hide Chatify.
---

## ❓ Why use Chatify?

Unlike in-game chats, Chatify is fully **private, unmoderated, and invisible** to third parties. It provides secure communication completely separate from game / app servers.
